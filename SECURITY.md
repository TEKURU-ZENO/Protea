# Security Policy

## Supported Versions

We actively support and apply security patches to the following versions of PROTEA:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within PROTEA, please report it immediately by contacting the maintainers. Do not open public GitHub issues for security vulnerabilities.

Please include:

- A description of the issue.
- Steps to reproduce or a proof of concept.
- The potential impact.

We will acknowledge receipt of your report within 48 hours and provide a timeline for resolution.
